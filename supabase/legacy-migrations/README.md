# Migraciones heredadas

Estos archivos documentan la evolución previa del esquema. No son una fuente
activa de despliegue y no deben moverse de vuelta a `supabase/migrations/`.

La fuente activa es una única línea base con marca de tiempo generada desde el
esquema remoto validado. Las modificaciones futuras deben usar migraciones con
marca de tiempo creadas por la CLI de Supabase.
